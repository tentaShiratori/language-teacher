# Ollama 構築

判定は端末内の Ollama だけを使う（[ADR 0002](./adr/0002-local-ollama.md)）。このマシンは NVIDIA GeForce RTX 4070 Ti（VRAM 12GB 級）を前提にする。アプリは起動時に Ollama とモデルを確認し、無ければ判定を止めて、以下と同じ手順を画面に出す。

## 入れるもの

1. [Ollama for Windows](https://ollama.com/download/windows)
2. 既定モデル `qwen3:8b`
3. （任意）`qwen3:14b` — 設定で切り替えるときだけ

インストーラが GPU（CUDA）を拾う。CPU だけになる場合は、後述の確認を見る。

## 手順

1. 上のページから Windows 用インストーラを入れて完了する。トレイに Ollama がいれば起動している。
2. mise の入ったターミナルでモデルを取る。

```bash
ollama pull qwen3:8b
```

14B も使うなら続ける。

```bash
ollama pull qwen3:14b
```

3. 応答を確かめる。

```bash
ollama run qwen3:8b
```

日本語で短い質問を打ち、返事が返ればよい。抜けるのは `/bye`。

4. HTTP 口は既定で `http://127.0.0.1:11434`。アプリの設定が空ならこの URL を使う。

```bash
ollama list
```

`qwen3:8b` が一覧にあれば、アプリから叩ける。

## アプリ側の前提

| 項目       | 既定                                                   |
| ---------- | ------------------------------------------------------ |
| ベース URL | `http://127.0.0.1:11434`                               |
| モデル     | `qwen3:8b`                                             |
| 切替       | 設定で `qwen3:14b`                                     |
| 呼び出し   | OpenAI 互換 `POST /v1/chat/completions`。Rust から行う |

WebView の `fetch` では呼ばない。CORS とキー露出を避ける。

## 起動時の検知

アプリ起動（と設定変更のあと）に次を見る。

1. `GET {base}/api/tags` が成功するか
2. 一覧に、設定中のモデル名が含まれるか

失敗したら判定操作を無効にし、この文書と同じ手順をアプリ上に出す。区別する文言は次。

- Ollama に届かない: インストールと、トレイで Ollama が動いているかを先に書く
- Ollama はあるがモデルが無い: `ollama pull` だけを先に書く

アプリは `ollama pull` を代行しない。

## GPU が使われているか

```bash
nvidia-smi
```

`ollama run` 中にプロセスが GPU メモリを使っていればよい。使っておらず返事が極端に遅いときは、NVIDIA ドライバを入れ直す。内蔵ディスプレイ用の仮想モニタだけが見えている状態では、4070 Ti が無効になっていないかをデバイスマネージャで確認する。

8B は 12GB に余裕を持って載る。14B（Q4 相当）も載るが、Tab ごとの判定は遅くなる。

## よくある失敗

| 症状                          | 見ること                                                         |
| ----------------------------- | ---------------------------------------------------------------- |
| アプリが「Ollama に届かない」 | トレイの Ollama、ファイアウォール、URL が `127.0.0.1:11434` か   |
| 「モデルが無い」              | `ollama list`。タグ名が設定の文字列と一致するか                  |
| 判定が終わらない              | 14B にしていないか。初回はモデルのロードで数十秒かかることがある |
| 返事が英語の解説ばかり        | プロンプトが JSON 固定を要求しているか。アプリ側の問題           |

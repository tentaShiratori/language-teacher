# 判定

用語は [CONTEXT.md](../CONTEXT.md)。画面への出し方は [design.md](./design.md)。モデルの起動は [ollama.md](./ollama.md)。

## 結論

`適切 = 意味が原文と合う ∧ 文法が破綻していない`。

自然さとトーンは結論に入れない。[指摘](../CONTEXT.md) は適切でも不適切でも出す。不適切なら [直した訳文](../CONTEXT.md) も出す。指摘は適切さの判定には使わない。

ニュース記事でも自分の作文でも、判定は同じである。

## 言語共通

英語も次の型に合わせる。

| 結果           | 条件                                                                     |
| -------------- | ------------------------------------------------------------------------ |
| 不適切（意味） | 訳文が原文と別のことを言っている。主語・否定・時制・数量の取り違えを含む |
| 不適切（文法） | 述語がない、一致が壊れている、語順が通らない                             |
| 指摘           | 適切でも不適切でも出す。直し方を母語で書く                               |
| 直した訳文     | 不適切のとき必須。意味と文法を直した学習言語の全文                       |
| 見ない         | 米語／英語の綴り差だけ。指摘にもしない                                   |

指摘は母語（日本語）で一文。不適切なら、どこが不適切かと直し方も書く。十分自然なら「このままで自然」でよい。直した訳文は指摘と分け、学習言語の全文にする。

## 中国語（簡体）

字体は簡体だけ。繁体で書かれていても、字体の違いは見ない（不適切にも指摘にもしない）。別の意味になっていれば意味の不適切。

| 現象                | 扱い           |
| ------------------- | -------------- |
| 動詞がない          | 不適切（文法） |
| 語順が通らない      | 不適切（文法） |
| 了 / 着 / 过 の誤り | 指摘           |
| 量詞の誤り          | 指摘           |
| 通じるが不自然      | 指摘           |

## 韓国語

| 現象                          | 扱い           |
| ----------------------------- | -------------- |
| 述語がない                    | 不適切（文法） |
| 活用が壊れている              | 不適切（文法） |
| 助詞の取り違え（を／が など） | 不適切（文法） |
| 은/는 と 이/가 の揺れ         | 指摘           |
| 敬語のずれ                    | 指摘（トーン） |

## ドイツ語

| 現象               | 扱い           |
| ------------------ | -------------- |
| 格が違う           | 不適切（文法） |
| 人称変化が違う     | 不適切（文法） |
| 動詞第二位が崩れる | 不適切（文法） |
| 性・冠詞が違う     | 不適切（文法） |
| 通るが不自然       | 指摘           |

## LLM に渡すもの

判定対象は今の [文](../CONTEXT.md) だけである。材料には [原文](../CONTEXT.md) 全体を付ける。代名詞と省略を、原文の他の文と矛盾させないため。

```text
学習言語: {英語|中国語（簡体）|韓国語|ドイツ語}
原文:
{全文}

対象の文:
{今の文}

訳文:
{今の訳文}
```

訳文が空なら LLM を呼ばない。

## 応答の形

Rust 側は JSON 以外を捨ててやり直す（最大1回）。フィールドは次に固定する。

```json
{
  "tekisetsu": true,
  "imi": true,
  "bunpo": true,
  "shiteki": "このままで自然",
  "naoshitaYakubun": null
}
```

| フィールド        | 型             | 規則                                                                |
| ----------------- | -------------- | ------------------------------------------------------------------- |
| `tekisetsu`       | bool           | `imi && bunpo` と一致させる。ずれて来たら `imi && bunpo` を採用する |
| `imi`             | bool           | 意味が原文と合うか                                                  |
| `bunpo`           | bool           | 文法が破綻していないか                                              |
| `shiteki`         | string \| null | 適切でも不適切でも残す。十分自然なら短文でよい                      |
| `naoshitaYakubun` | string \| null | 不適切なら直した訳文の全文。適切なら null                           |

プロンプト本文は `apps/app` の Rust に置く。学習言語ごとの破綻表を、その言語のときだけプロンプトに足す。模範解答を求めない。

## やり直し

同じ文を訳し直して再判定できる。その文の判定は上書きする。試行の履歴は持たない。
